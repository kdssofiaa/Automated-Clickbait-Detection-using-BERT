# Automated Clickbait Detection using BERT

A transformer-based NLP model that classifies news headlines as clickbait or not clickbait to support digital media literacy. It won a Silver Award at iCE-CInno 2026 (Clickwise).

**Dataset:** 32,000 headlines, labelled and preprocessed by me using Pandas.

**Tools:** Python, PyTorch, Hugging Face Transformers, Pandas, Google Colab.

**Result:** 98.6% accuracy.

**How to view / run:**
- The notebook with saved outputs and results is in `CLICKBAIT_DETECTION_USING_BERT.ipynb`.
